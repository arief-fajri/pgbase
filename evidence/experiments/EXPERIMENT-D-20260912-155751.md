## Scenario

(1) A migrator blocked by an external lock fails cleanly and boundedly;
(2) after the failure is removed, re-running migrations reproduces an
identical, valid schema (determinism; advisory-lock serialization); (3) a
fresh DB migrated by the same binary yields the identical schema fingerprint.

## Procedure

`bash evidence/experiments/EXPERIMENT-D.sh`

1. Fresh DB `pgbase_exp_d`; `migrate up`; record schema fingerprint
   (`pg_dump --schema-only`, pg_dump-18 `\restrict` marker filtered out).
2. Block `_migrations` with an external ACCESS EXCLUSIVE lock; `migrate up`
   must fail cleanly and boundedly; release via `pg_terminate_backend`.
3. Re-run `migrate up`; compare recovered fingerprint to clean.
4. Second fresh DB `pgbase_exp_d2`; `migrate up`; compare fingerprint
   (cross-database determinism).
5. Count internal `_`-prefixed tables (expect 15).

## Results

- blocked migrate: rc=**1**, elapsed **30 s** (bounded; exactly lock_timeout)
- recovered schema fingerprint **matches** clean
- fresh DB schema fingerprint **matches** clean
- internal tables (data db): **15**
